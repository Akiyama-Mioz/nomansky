## 一、TELEMETRY 区 — 飞控遥测数据

数据来源: PX4 飞控通过 MAVLink 消息实时发送，Zero3W 接收并解析。

### Link — 串口连接状态

| 属性 | 说明 |
|------|------|
| **显示** | `OK` (绿色) 或 `NO` (红色) |
| **含义** | Zero3W 和 PX4 之间的串口是否正常通信 |
| **MAVLink 来源** | HEARTBEAT 消息 (1Hz) |
| **正常值** | `OK` |

### Mode — 飞行模式

| 属性 | 说明 |
|------|------|
| **显示** | `AUTO.LOITER`, `OFFB`, `POS`, `MAN`, `RTL` 等 |
| **含义** | PX4 飞控当前所处的飞行模式 |
| **MAVLink 来源** | HEARTBEAT.custom_mode |
| **正常值** | 根据飞行阶段变化 |
| **常见值** | `MAN`=手动, `POS`=定点, `AUTO.LOITER`=自动悬停, `AUTO.HOLD`=自动保持(悬停等待), `OFFB`=板载计算机控制, `RTL`=返航, `AUTO.LAND`=自动降落, `AUTO.TKOFF`=自动起飞 |

### Armed — 解锁状态

| 属性 | 说明 |
|------|------|
| **显示** | `ARM` (绿色) 或 `DSRM` (灰色) |
| **含义** | 飞控是否已解锁（电机是否可转） |
| **MAVLink 来源** | HEARTBEAT.base_mode bit 7 |
| **正常值** | 地面时 `DSRM`，飞行中 `ARM` |

### State — 系统状态

PX4 上电后会依次经过以下状态。这是飞控的**生命周期**，不是飞行模式。

| 显示 | 值 | 含义 | 能 ARM 吗？ | 说明 |
|------|-----|------|------------|------|
| **UNINIT** | 0 | 未初始化 | ❌ | 飞控刚上电，传感器自检中。若长时间卡在这里，说明缺 GPS 信号、缺遥控器、或电池检测报错 |
| **BOOT** | 1 | 启动中 | ❌ | 加载参数、检测传感器硬件 |
| **CAL** | 2 | 校准中 | ❌ | 陀螺仪/加速度计校准。通常持续 2~3 秒 |
| **STBY** | 3 | 待命 | ✅ | 初始化完成，可以解锁。**正常地面状态** |
| **ACT** | 4 | 运行中 | — | 已解锁，飞控正在工作。**正常飞行状态** |
| **CRIT** | 5 | 严重故障 | ❌ | 传感器故障、Failsafe 触发等。需要检查 |
| **EMERG** | 6 | 紧急状态 | ❌ | 失控保护触发（如摔机检测） |
| **PWROFF** | 7 | 关机 | ❌ | 飞控即将断电 |

**状态转换流程**:
```
上电 → UNINIT → BOOT → CAL → STBY → (Armed) → ACT
                  ↑        ↓
                  │   (Disarmed)
                  └──────────┘

任意状态 ──故障──→ CRIT / EMERG
```


### Roll — 横滚角

| 属性 | 说明 |
|------|------|
| **显示** | `±XX.X°` |
| **含义** | 无人机绕前后轴（机头-机尾）的旋转角度。正值=右倾，负值=左倾 |
| **MAVLink 来源** | ATTITUDE.roll (rad) → 转换为度 |
| **刷新率** | 50~100 Hz |
| **正常范围** | 悬停时 ±5°，飞行时 ±30° |

### Pitch — 俯仰角

| 属性 | 说明 |
|------|------|
| **显示** | `±XX.X°` |
| **含义** | 无人机绕左右轴的旋转角度。正值=抬头（机头上扬），负值=低头 |
| **MAVLink 来源** | ATTITUDE.pitch (rad) → 转换为度 |
| **刷新率** | 50~100 Hz |
| **正常范围** | 悬停时 ±5°，前进时 -15°~0° |

### Yaw — 航向角

| 属性 | 说明 |
|------|------|
| **显示** | `±XXX.X°` |
| **含义** | 无人机机头指向的方向。0°=北，90°=东，±180°=南 |
| **MAVLink 来源** | ATTITUDE.yaw (rad) → 转换为度 |
| **刷新率** | 50~100 Hz |
| **正常范围** | -180° ~ +180° |

### Alt — 相对高度

| 属性 | 说明 |
|------|------|
| **显示** | `X.X m` 或 `--` |
| **含义** | 无人机相对起飞点的高度 |
| **MAVLink 来源** | GLOBAL_POSITION_INT.relative_alt (mm) → 转换为米 |
| **刷新率** | 10~20 Hz |
| **正常值** | 0 ~ 120 m |

**数据来源**: 这个高度不是单一传感器给出的，而是 PX4 的 EKF2（扩展卡尔曼滤波器）融合多种传感器后输出的估计值：

| 传感器 | 测量内容 | 精度 | 作用 |
|--------|---------|------|------|
| **气压计** (Barometer) | 大气压强 → 绝对海拔 | ±1~2m | 主力高度来源，所有飞行器都有 |
| **GPS** | 卫星定位 → 3D 位置 | ±3~10m (垂直) | 修正气压计的长期漂移 |
| **激光/超声波测距仪** (Range Finder) | 到地面的距离 | ±0.05m | 低空 (<10m) 时极大提升精度 |
| **光流计** (Optical Flow) | 图像位移 → 水平速度 | — | 提供水平速度，不直接测量高度 |
| **IMU 加速度计** | 垂向加速度 → 二次积分 | 会漂移 | 提供高频变化，与气压计互补 |

**融合逻辑**:
```
高度估计 = 气压计 (主力, 长期稳定)
         + 加速度计 (补充高频变化)
         + GPS (修正气压计的温漂/气压变化)
         + 测距仪 (近地时精度最高, EKF 优先生效)
```

**你当前的情况**：没有接 GPS、没有测距仪，高度完全依赖**气压计 + IMU**，精度约 ±1~2m。室内气压波动时可能有零点漂移。

**`--` 的含义**：如果飞控还没完成初始化（UNINIT 状态），EKF 尚未收敛，此时 `relative_alt` 字段可能无效，显示为 `--`。

### Vel NED — 速度（NED 坐标系）

| 属性 | 说明 |
|------|------|
| **显示** | `+X.X +X.X +X.X m/s` |
| **含义** | 无人机在 NED (北-东-地) 坐标系下的三轴速度 |
| **三个值** | vx=北向速度 (正值=向北)，vy=东向速度 (正值=向东)，vz=垂向速度 (正值=下降) |
| **MAVLink 来源** | LOCAL_POSITION_NED.vx / .vy / .vz |
| **刷新率** | 20~50 Hz |

### Bat — 电池电压

| 属性 | 说明 |
|------|------|
| **显示** | `XX.X V` 或 `--` |
| **含义** | 无人机电池电压 |
| **MAVLink 来源** | BATTERY_STATUS.voltages[0] (mV) → 转换为 V |
| **正常值** | 3S 电池 ~11.1V，4S 电池 ~14.8V，6S 电池 ~22.2V |
| **注意** | USB 供电时显示 `--`（无效值） |

### EKF — 扩展卡尔曼滤波器状态

| 属性 | 说明 |
|------|------|
| **显示** | `OK` (绿色) 或 `OFF` (红色) |
| **含义** | PX4 的姿态/位置估计算法是否正常运行 |
| **MAVLink 来源** | ESTIMATOR_STATUS.health_flags |
| **正常值** | `OK` |

## 二、COMMANDS 区 — 控制指令状态

数据来源: Zero3W 本地的命令历史（由 `test_mavlink_control.py` 调用 `_hud_log_cmd()` 写入）。

### Last Cmd — 最近一次指令

| 属性 | 说明 |
|------|------|
| **显示** | 指令名称，如 `SET_MODE GUIDED`, `ARM`, `TAKEOFF 3m`, `FWD 2s` |
| **含义** | Zero3W 最近一次向 PX4 发送的控制指令 |
| **常见值** | `ARM`, `DISARM`, `TAKEOFF 3m`, `LAND`, `RTL`, `FWD`, `BACK`, `LEFT`, `RIGHT`, `UP`, `DOWN`, `HOVER` |

### Result — 指令执行结果

| 属性 | 说明 |
|------|------|
| **显示** | `ACCEPTED` (绿), `TEMP_REJECTED` (橙), `DENIED` (红), `SENT` (绿), `DONE` (绿), `NO_ACK` (红) |
| **含义** | PX4 是否接受了指令 |
| **ACCEPTED** | 指令已接受，正在执行 |
| **TEMP_REJECTED** | 临时拒绝（前置条件不满足，稍后可重试） |
| **DENIED** | 永久拒绝（权限/配置问题） |
| **SENT** | 已发送（等待确认） |
| **DONE** | 指令执行完成 |

### Vel Cmd — 当前速度指令

| 属性 | 说明 |
|------|------|
| **显示** | `+X.X +X.X +X.X yr=X.XX` |
| **含义** | Zero3W 当前正在发送给 PX4 的 OFFBOARD 速度指令 |
| **三个值** | vx=前后速度, vy=左右速度, vz=上下速度 (m/s)，yr=偏航角速度 (rad/s) |
| **注意** | 全零 = 悬停指令，仅在 OFFBOARD 模式下有效 |

### 指令历史

| 属性 | 说明 |
|------|------|
| **显示** | `HH:MM:SS  CMD_NAME -> RESULT` |
| **含义** | 最近 3 条已执行的指令及其时间戳和结果 |

## 三、LOG 区 — 事件日志

数据来源: `hud._log()` 方法写入，最多显示 5 条。

### 启动日志

| 日志内容 | 含义 |
|----------|------|
| `HUD ready 1920x1080 BGRA` | HUD 模块启动，检测到的屏幕分辨率和像素格式 |
| `PX4 connected` | 收到 PX4 第一个心跳包，通信建立 |
| `TX: Hello, PX4!` | Zero3W 发送的测试消息 |

### 模式变化日志

| 日志内容 | 含义 |
|----------|------|
| `Mode: OFFB` | 飞控模式切换 |
| `Armed: YES` / `Armed: NO` | 解锁/上锁状态变化 |

### 消息统计日志 (每 5 秒)

| 日志内容 | 含义 |
|----------|------|
| `RX: ATTITUDEx500 HIGHRES_IMUx250 LOCAL_POSITION_NEDx150` | 最近 5 秒内收到的 Top 3 消息类型及其数量 |

### 外部消息日志

| 日志内容 | 含义 |
|----------|------|
| `[INFO] Hello, PX4!` | PX4 或其他设备通过 MAVLink STATUSTEXT 发送的消息 |
| `[ERR] ...` | PX4 报错信息 |

## 四、底部状态行

### Frame — 累计渲染帧数

| 属性 | 说明 |
|------|------|
| **显示** | `#XXXX` |
| **含义** | HUD 启动以来累计渲染的画面帧数 |
| **刷新率** | 每秒 +10（10Hz 渲染） |
| **用途** | 判断 HUD 是否卡死（如果数字不动 = 卡死） |

### Time — 运行时间

| 属性 | 说明 |
|------|------|
| **显示** | `XXs` |
| **含义** | HUD 程序启动以来的运行时间（秒） |

| MAVLink 消息 | 频率 | HUD 字段 |
|-------------|------|----------|
| HEARTBEAT | 1 Hz | Link, Mode, Armed, State |
| ATTITUDE | 50~100 Hz | Roll, Pitch, Yaw |
| LOCAL_POSITION_NED | 20~50 Hz | Vel NED |
| GLOBAL_POSITION_INT | 10~20 Hz | Alt |
